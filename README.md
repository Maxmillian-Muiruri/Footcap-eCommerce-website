# Footcap - Find Your Footwear

## Project Overview

Footcap is a responsive e-commerce website homepage designed for showcasing and selling footwear products. The site features a modern and clean design with multiple sections including hero banner, product collections, bestsellers, special offers, services, Instagram posts, and a footer with contact and account information.

## Features

- Responsive layout optimized for various screen sizes
- Interactive navigation bar with toggle menu for mobile devices
- Hero section with promotional banner and call-to-action button
- Product collections and bestsellers with filtering options
- Special offers and call-to-action sections
- Services and Instagram post previews
- Footer with contact details, account links, opening times, and newsletter subscription
- Smooth scroll behavior and "go to top" button

## Technologies Used

- HTML5 for markup structure
- CSS3 for styling and responsive design
- JavaScript for interactive navbar toggle and scroll effects
- Google Fonts for typography
- Ionicons for icons

## Usage

1. Clone or download the repository.
2. Open `index.html` in a web browser to view the homepage.
3. Modify the HTML, CSS, and JS files as needed to customize the site.
